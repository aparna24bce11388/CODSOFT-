# CODSOFT Java Development Internship Projects

I am a 3rd year B.Tech Computer Science Engineering student, and this repository contains the projects completed during my Java Development Internship at CODSOFT. These projects helped me improve my understanding of Core Java, Object-Oriented Programming (OOP), problem-solving skills, and console-based application development.

The repository includes projects such as Student Grade Calculator, ATM Interface, and Student Management System. While working on these projects, I implemented important Java concepts including classes and objects, methods, constructors, loops, conditional statements, ArrayList, user input handling, and validation techniques.

The Student Grade Calculator project calculates total marks, average percentage, and grades based on user input. The ATM Interface project simulates banking operations such as deposit, withdrawal, and balance checking using Java classes and methods. The Student Management System project manages student records with functionalities like adding, searching, removing, and displaying student details.

Through these projects, I gained hands-on experience in Java programming and strengthened my logical thinking and development skills. This repository represents my learning journey, practical implementation of programming concepts, and continuous growth as a software development student.
